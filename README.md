# Polyglot Coach

A language-learning app for **English, French and Dutch (Flemish)**, from beginner (A1) to expert (C2).
The same code runs in two places:

- **On claude.ai** as an artifact (web page), where the AI features use Claude directly.
- **On Android** as an APK, built automatically by GitHub Actions with [Capacitor](https://capacitorjs.com).

## Install on your phone

1. Open the **Releases** page of this repository on your phone.
2. Open the latest `build-N` and tap **Polyglot.apk**.
3. Allow installing from your browser if Android asks.
4. Every new build installs as an update (same signing key), so your progress is kept.

## Project structure

```
src/polyglot.html            ← THE APP: all HTML, CSS and JavaScript in one file
scripts/build-web.js         ← copies the app into www/ for Android (local fonts, capacitor.js)
capacitor.config.json        ← app id (com.agedocollins.polyglot), name, web folder
android/                     ← native Android project generated by Capacitor
  app/build.gradle           ← version number (= build number) and signing key
  app/src/main/AndroidManifest.xml  ← permissions (notifications, text-to-speech)
  app/src/main/res/          ← icon and splash screen
.github/workflows/build-apk.yml     ← builds the APK on every push to main
```

## How to read `src/polyglot.html`

It is one file, organised in sections (search for `/* ----------`):

| Section | What it does |
|---|---|
| `<style>` `:root` | Design tokens: colours (60-30-10), 8px spacing grid, radii, type scale |
| `ICONS` | All icons as inline outline SVG |
| `UI STRINGS FR / EN` | Every text of the interface, in French and English (`t("key")`) |
| `LANGUAGE PACKS` | One entry per language (name, voice, articles). Add a language here |
| `WORDS`, `EXPR` | Built-in words and expressions of the day (fallback when no AI) |
| `GRAMMAR`, `SYLL` | Built-in lessons and the full A1→C2 syllabus (other lessons are AI-generated once, then cached) |
| `VTH`, `NOUNS`, `SCEN` | Vocabulary themes, le/la & de/het nouns, conversation scenarios |
| `STATE` | Everything you do is saved in `localStorage` under the key `pc` |
| `AUDIO` | Text-to-speech, karaoke highlighting, "repeat after me" |
| `TODAY` | Word + expression of the day cards, daily goal ring |
| `LEARN` | Grammar path (locked in order), exams, vocabulary, mistakes review, articles game |
| `SPEAK` | AI conversation with corrections |
| `PROGRESS` | Weekly report, badges, stats |
| `SETTINGS`, `MANDATORY POPUP` | Popup time, languages, the word-of-the-day popup you can't skip |
| `ANTHROPIC API`, `ANDROID` | Used only in the APK: AI with your own API key, native voice, notifications, back button |
| `BOOT` / `ENVIRONMENT` | Detects where the app runs (claude.ai, Android or browser) |

Good first things to study:
- `go(v)` — how the app switches screens.
- `renderToday()` — how a screen is built from data with template strings.
- `runQuiz()` — a small reusable quiz engine.
- `mistakes()` — spaced repetition (1, 3, 7 days).
- `sayLines()` / `speakOne()` — async/await audio sequence with highlighting.

## AI in the APK

Outside claude.ai there is no built-in Claude access. In **Settings** you can paste an
[Anthropic API key](https://console.anthropic.com) to turn on the AI parts (conversation, generated lessons,
exams, vocabulary, new word of the day). It is billed to your Anthropic account and stored only on the phone.
Without a key, everything built-in still works offline.

## Build locally (optional)

```bash
npm ci
npm run sync            # builds www/ and copies it into android/
cd android && ./gradlew assembleDebug
```

## Signing key

`android/app/polyglot.keystore` is a personal debug key so every build installs as an update.
Because this repository is public, anyone could sign an APK with it. Only install APKs from **your own** Releases page.
